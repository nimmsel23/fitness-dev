# Journal Solo (Standalone PWA)

This is a focused, lightweight version of the AlphaOS Unified Journal, designed to run as an independent application.

## Purpose

- **Minimalist Journaling**: Quick access to your daily reflections, workout notes, and habit logs.
- **Independence**: Can be added to the mobile home screen as a dedicated "Reflection" icon.
- **Day One Experience**: Provides the full immersive journaling UI without the surrounding fitness tracking menus.

## Build & Deployment

- **Entry Point**: `pwa/standalone/journal/index.html`
- **Build Output**: Located at `dist/standalone/journal/index.html`.
- **Access**: Deployed at `/standalone/journal/index.html`.

## Development

Changes made to the core components in `pwa/src/views/Journal/` will automatically update both the main app and this standalone version.
